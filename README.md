# Blinkon Group — Luxury Real Estate Web Platform

A modern, high-performance architectural luxury real estate web platform built with React 18, TypeScript, Tailwind CSS, GSAP ScrollTrigger, and Framer Motion.

## 🚀 Features
- **Cinematic 3D Video Scrubbing**: Fullscreen architectural frame sequences for Hero, Drone-to-Interior reveal, and Day-to-Night diurnal metamorphosis.
- **Interactive Portfolio & Dossier**: Curated landmark collection with architectural specifications modal and category filters.
- **Glassmorphic UI**: Ultra-clean frosted glass cards with 10px blur and hairline grid backgrounds.
- **Scroll Animations & Kinetic Typography**: Smooth slide-in, pop-up, and typewriter heading effects on scroll.
- **Optimized Performance**: Intersection-aware lazy sequence loading and modular Rollup code splitting.

## 🛠️ Tech Stack
- **Framework**: React 18 + Vite 5 + TypeScript
- **Styling**: Tailwind CSS 3.4
- **Animation**: GSAP ScrollTrigger + Framer Motion + Lenis Smooth Scroll
- **Icons**: Lucide React + Tabler Icons

## 💻 Getting Started

### Installation
```bash
npm install
```

### Development
```bash
npm run dev
```

### Production Build
```bash
npm run build
```
